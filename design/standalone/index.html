Translation Editor design, first pass

A translation editor that behaves like a book

Three rules everything else follows from. Source text is set like a printed page and the translation sits beside it in the same face and rhythm, so the eye compares like with like. Controls are ranked by what they cost, not by how often they are used: one filled control per screen, and it commits something. Every outline is drawn rather than printed, so the thing reads as marked-up paper and not as a form.

What was wrong before

Nine buttons in a row, identical in size and weight, so nothing said which one spends money and which one changes a filter. No sense of place: one endless list, no page, no contents, and a bookmark stored as a pixel offset that threw you to the end of the document whenever anything redrew. And a form-like surface — boxes, bars, badges — for work that is entirely about reading and writing prose.

What is deliberately absent

There are no cards, no gradients, no icons standing in for words. Messages stay on the page until dismissed rather than fading out mid-sentence, and nothing pretends to be text that has not arrived yet. The single animation is a rule inked in beneath the line being translated; it runs once, and it stops when that line comes back.
